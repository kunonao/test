# スマホ（Android）のファイル整理ツール

ダウンロードフォルダなどにたまった、ごちゃごちゃのファイルを片付けるツールです。

- **種類別に分ける**: 画像・動画・音声・PDF・文書・表計算・プレゼン・アプリ・圧縮ファイル・その他 のフォルダへ振り分けます
- **同じようなファイルは最新だけ残す**:
  - 中身がまったく同じファイル（名前が違っても見つけます）
  - `資料.pdf` / `資料 (1).pdf` / `資料 (2).pdf` / `資料-1.pdf` のような、同じ名前の古い版
  - いちばん新しいものだけを残して `資料.pdf` という名前にそろえ、ほかは **`_削除候補` フォルダへ移します**

## 安全のための工夫

| 工夫 | 内容 |
|---|---|
| いきなり消さない | 古いものは `_削除候補` フォルダへ「移す」だけです。中身を見て、要らなければ自分でフォルダごと消します |
| まず下見 | `--apply` を付けない限り、何をするかを表示するだけで何も変更しません |
| 元に戻せる | 移動の記録を `logs/` に保存します。`--undo` で全部元の場所に戻せます |
| 触らないもの | 自分で作ったフォルダの中身、隠しファイル、ダウンロード途中のファイル（`.crdownload` など）、`Android` フォルダ（アプリのデータ）。カメラの写真（`DCIM`）は `--force` を付けたときだけ |
| 上書きしない | 移動先に同じ名前があれば `名前 (2).pdf` のように別名にします |

## いちばん簡単な使い方：PC の Claude Code に頼む（おすすめ）

PC とスマホを USB ケーブルでつなぎ、PC の Claude Code にスマホを操作してもらいます。

### ① スマホで「USB デバッグ」を ON にする（最初の1回だけ）

1. **設定 → デバイス情報**（機種によっては「端末情報」→「ソフトウェア情報」）を開く
2. **ビルド番号** を 7 回続けてタップ →「開発者になりました」と出る
3. **設定 → システム → 開発者向けオプション**（機種によっては設定のトップ）を開く
4. **USB デバッグ** を ON

### ② USB ケーブルでつなぐ

スマホに「USB デバッグを許可しますか？」と出たら、
「このパソコンからのアクセスを常に許可する」にチェックして **許可** を押します。
（充電専用のケーブルだとつながりません）

### ③ PC の Claude Code に頼む

このフォルダ（`android-organizer`）で Claude Code を起動して、例えばこう頼みます。

> スマホのダウンロードフォルダを整理して

Claude Code が `adb` の準備 → 下見 → 結果の説明 → あなたの OK → 実行 の順に進めます。
（手順は同じフォルダの `CLAUDE.md` に書いてあり、Claude Code はそれに従います）

終わったら、スマホのファイルアプリで `Download/_削除候補` を開いて中身を確認し、
要らなければフォルダごと削除してください。

## 自分でコマンドを打つ場合

必要なもの: Python 3.8 以上、[Android SDK Platform-Tools](https://developer.android.com/tools/releases/platform-tools)（`adb`）

```bash
adb devices                                  # スマホが「device」と表示されれば OK
python organize.py --adb                     # 下見（何も変更しない）
python organize.py --adb --apply             # 実行
python organize.py --adb --dir /sdcard/Documents   # 別のフォルダを整理
```

| オプション | 意味 |
|---|---|
| `--apply` | 実際に移動する（付けなければ下見だけ） |
| `--dir フォルダ` | 整理するフォルダ（既定は `/sdcard/Download`） |
| `--exact-only` | 中身がまったく同じ重複だけを削除候補にする（名前が同じだけの古い版は残す） |
| `--no-sort` / `--no-dedupe` | 種類別の振り分けだけ／重複の整理だけ をしない |
| `-v` | 振り分け予定を全件表示 |
| `--undo logs/organize-log-….json` | 前回の整理を元に戻す（これも `--apply` を付けたときだけ実行） |
| `-s 番号` | スマホが複数つながっているとき（`adb devices` で確認） |

## スマホだけで完結させたい場合（Termux）

PC を使わず、スマホ上で直接動かすこともできます。

1. [Termux](https://termux.dev/) をインストール（F-Droid か GitHub 版がおすすめ）
2. Termux で次を実行（途中でファイルへのアクセス許可を求められたら「許可」）

   ```bash
   termux-setup-storage
   pkg install python
   ```

3. `organize.py` をスマホにコピーして、そのフォルダで

   ```bash
   python organize.py            # 下見
   python organize.py --apply    # 実行
   ```

## 気をつけること

- 「名前が同じだけで中身は別物」のファイル（例: いろいろなサイトから落とした `image.jpg` / `image (1).jpg`）も、
  古い版として削除候補になります。**下見の「中身は違います」と書かれた行は確認してください。**
  気になる場合は `--exact-only` を使うと、中身がまったく同じものだけを対象にします。
- 「最新」はファイルの更新日時で判断します。
- 整理後、ファイルアプリやギャラリーの表示が古いままのときは、アプリを開き直すか少し待ってください。
- `logs/` にはファイル名の一覧が残ります。要らなくなったら消して構いません（元に戻せなくなるだけです）。
