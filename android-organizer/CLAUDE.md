# このフォルダで Claude Code が守ること

利用者は、USB でつないだ Android スマホのファイル整理（主に `/sdcard/Download`）を頼んできます。
利用者はパソコンに詳しくない前提で、専門用語を避けた日本語で説明してください。

## 手順

1. `adb devices` でスマホがつながっているか確認する。
   - `adb` が無ければ、Android SDK Platform-Tools を公式ページ
     （https://developer.android.com/tools/releases/platform-tools）から入れる手伝いをする。
   - `unauthorized` ならスマホ画面の「USB デバッグを許可」を押してもらう。
   - 何も出なければ README.md の「USB デバッグを ON にする」手順を案内する。
2. **下見**: `python organize.py --adb`（別のフォルダなら `--dir`）。
3. 下見の結果を短くまとめて伝える: 種類別に何件動くか、削除候補が何件・何 MB か。
   特に「中身は違います」の行（名前は同じだが中身が別のファイル）は具体的に挙げて、残すべきものが無いか聞く。
   心配があれば `--exact-only` を提案する。
4. 利用者が **はっきり OK と言ってから** `python organize.py --adb --apply` を実行する。
5. 結果と、元に戻すコマンド（出力に表示される `--undo …`）を伝え、
   スマホのファイルアプリで `_削除候補` フォルダを確認して要らなければ消すよう案内する。

## 禁止事項

- スマホ上で `rm` などの削除コマンドを自分から実行しない。
  `_削除候補` フォルダの削除を頼まれた場合だけ、対象のフォルダの場所と中身の件数を示して、
  もう一度確認を取ってから実行する。
- `Android` フォルダ（アプリのデータ）は触らない。`DCIM`（カメラの写真）は利用者が明示的に望んだときだけ `--force` を付ける。
- `--apply` なしの下見を飛ばして、いきなり実行しない。
- このツールで足りない整理（例: 年月ごとに分けたい）を頼まれたら、まず下見できる形で提案し、同じく OK をもらってから行う。
