# STARBOOKS 入稿ルール（小説本に関係するところ）

2026-11-18 に公式マニュアルを読んでまとめたもの。最新の内容は公式サイトで確かめること。

## 一番大事な点

> 当社では、印刷トラブル防止のため「PDF/X-4準拠のPDF」でのご入稿を推奨しております。
> PDF/X-4形式でのご入稿のみ、当社での正常出力を保証いたします。

通常のPDFでも受け付けるが、仕上がりは保証されない。

## ルール一覧

| 項目 | ルール |
|---|---|
| ファイル形式 | InDesign・Word は PDF に変換して入稿。小説の PDF は画像化せず PDF のまま入稿する |
| フォント | すべて埋め込む。書き出した後、「文書のプロパティ」で埋め込まれているか確かめる（一部のフォントは、アプリによって埋め込み対象から外れることがある） |
| 文字の色 | K100、またはリッチブラック。Word の場合、文字色は「自動」ではなく「黒」にし、リンクは解除する。意図的なグレーの文字は入稿時に伝える |
| カラーモード | CMYK を推奨。モノクロでグレーを含む場合はグレースケール。CMYK のないソフトで作った場合、オンデマンドなら RGB でも可（オフセットは CMYK） |
| ページ | PDF は見開きではなく単ページ。本文は1つの PDF にまとめてよい。白紙ページも入れる。合計は必ず偶数 |
| 塗り足し | 仕上がりサイズに上下左右それぞれ3mm以上 |
| 切れ防止 | 裁断線の周辺（5mmほど）に、切れて困る絵や文字を置かない |
| ノドの余白 | ノド側の裁断線から最低10mmより内側に文章を収める。100ページを超える場合は15〜20mm |
| 解像度 | カラー印刷部分は350dpi、モノクロ印刷部分は600dpi |
| ノンブル | 必須ではない。ない場合はファイル名がノンブル代わり |
| ファイル名 | 半角英数字と「_」だけ。ページ順が分かる名前にする（例：`honbun.pdf`、`003_168.pdf`） |
| 入稿方法 | 圧縮して、会員ページ（お客さまノート）にアップロードするか、ファイル転送サービスを使う |
| 奥付 | 印刷所名を記載する |

## 避けたほうがいいもの

- **JUST PDF（JUST PDF 3／4）**：文字がランダムにアウトライン化され、その文字だけ太く見えることがある。起きた場合は全文字をアウトライン化すると太さがそろう。
- **Mac の印刷ダイアログからの PDF 化（Quartz）**：文字や画像が印刷されない現象がある。

## サイズ（単位 mm、天地 × 左右）

| 判型 | 仕上がり | 原稿サイズ（塗り足し3mm込み） |
|---|---|---|
| B5 | 257 × 182 | 263 × 188 |
| A5 | 210 × 148 | 216 × 154 |
| B6 | 182 × 128 | 188 × 134 |
| 新書 | 175 × 105 | 181 × 111 |
| 文庫 | 148 × 105 | 154 × 111 |

表紙・カバーは、背幅（と折り返し）を足したサイズになる。背幅は見積もりでページ数を入れると分かる。
