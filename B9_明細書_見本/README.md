# B9 明細書の見本（ダミー2人分）

打ち合わせで明細書（B9）の形を確かめるための**見本**です。本番の B9（明細書出力）のプログラムではありません
（B9 は、打ち合わせで形が決まってから作ります。2026-09-29 速水さん）。
人・案件・番号・要約はすべて架空です。

ファイル名は仕様どおり `{年}_報奨金明細書_{従業員ID}_{氏名}.pdf`（1人1ファイル）にしてあります。

## 今回の形（2026-09-29 に決めたこと）

- 各行に「元の金額・受け取る人数・計算・お支払額」を出す。**計算式は4報奨とも**出す。
- **評価ランクと期間の按分（日割り）は登録後報奨だけ**。他の3報奨は1回の出来事で決まるので日割りの列を置かない。
- 「計算」欄は、プログラムと同じ順（元の金額×割合×日数÷年日数÷人数）で書き、途中で丸めず最後に100円未満を切り捨てる。
  式で出した額と②の個人支給額が一致することを、見本を作るときに1行ずつ確かめている。
- 出願時報奨の代理作成：発明者は「×3/4÷人数」、代理作成者は「×1/4」（人数で割らない）。
- 受け取る人数は、発明者のうち当社（所属会社コード 0000003441）の人だけ。別会社の共同発明者は数えない（管理台帳 L18・L19）。
- 部署は明細書から外した。

## どう作っているか

見本の数字が、そのまま今のプログラムの答えになるように、本番と同じ部品を通しています。

1. ダミーの①（4報奨）を、本物の列定義と本物の書き出し（`write_result_rows`）で作る。配分は本物の関数
   （出願時報奨は `_apply_proxy_distribution`、登録後報奨は `decide_amount`＋`c3_distribute`、他は `c3_distribute`）。
2. 本物の B7・B8（`run_b7_b8`）に通して、②受給者別明細と受給者別集計を作る（警告0件で通ること）。
3. 明細書は②だけから組み立てる。小計・件数・合計は受給者別集計（B8）とも照合し、合わなければ止める。

使ったコード：`kunonao/houshoukin` ブランチ `claude/inspiring-lamport-rlpb1o`（`7ebc578`。②に基準報奨金額・支払対象者数・
配分モードを足した版）。

## 作り直し方

```
python make_mihon.py <houshoukin のプログラムフォルダ>
```

openpyxl が要ります。PDF は Chromium（Chrome）で印刷します（見つからないときは環境変数 `CHROME` で場所を指定）。
フォントは Yu Gothic・メイリオ（Windows）、無ければ IPA ゴシックを使います。

## 打ち合わせで確かめたいこと

仕様書の下書き（`kunonao/houshoukin` の `プログラム/docs/フロー仕様/B9_明細書出力フロー.md`「打ち合わせで決めること」）にまとめています。
特に、見本で目に見える点：

- 「社員番号」欄：今の仕様では従業員ID（見本の `t-yamada` のような形）を出す。旧明細書は人事データの従業員番号（数字）を
  出し、従業員IDは PDF のファイル名にだけ使っていた（旧マクロの「報奨金データ」と「empl」で確認）。
- 欄外の注記の文言（旧明細書の4行を、式を出すことに合わせて書き直した案）。
- 報奨の並び順：今の仕様は報奨種別コード順（出願時→登録時→登録後→外国出願時）。旧明細書は国内出願→海外出願→登録時→登録後。
